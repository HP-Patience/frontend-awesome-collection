# 复刻项目

这里存放已经开始实现的独立作品，包括完整网站、单页复刻和局部交互实验。已收录 [Rive 猫爪按钮](rive-cat-paw/README.md)：复用原站动画资源的局部交互演示，支持单文件离线运行。

另收录 [Alche Studio](alche-studio/README.md)：原站公开静态构建的本地化版本，保留实时 WebGL、滚动动效、多页面和调节面板。

另收录 [Ripple Shader](ripple-shader/README.md)：独立实现的原生 WebGL 水波画廊，连续采样指针路径、自然回收拖尾，支持三档模式、触屏与单文件离线导出。

- 使用小写英文与短横线命名，例如 `studio-portfolio`。
- 按作品组织，不按技术栈或完成状态分目录；项目状态变化时不移动目录。
- 每个项目自行管理运行环境、依赖、配置和锁文件，不要求统一框架。
- 在项目 README 中记录原作来源、实现范围、运行命令、预览与复盘。
- 项目截图放在自己的 `screenshots/` 中，运行素材按所用框架的约定存放。
- 暂不建立共享组件包；出现实际复用需求后再讨论提取。

新增项目时可复制[仓库首页的单项目 README 模板](../README.md#单项目-readme-模板)，完成后更新[项目索引](../README.md#项目索引)。只有收藏链接、尚未开始实现的内容请记在[灵感收藏](../collection.md)。
