# 学习笔记

这里整理跨项目可复用的前端经验。目前暂无专题笔记，按实际积累逐步添加，不预建空白文章。

## 适合放在这里的内容

- 多个作品都用到的布局与响应式处理方法。
- 动画节奏、缓动、滚动联动等通用实现经验。
- 可访问性、加载体验与性能优化的实践总结。

单个作品的还原难点、技术取舍和效果截图仍放在对应项目中，避免重复维护。

## 组织约定

- 一篇笔记聚焦一个主题，文件名使用小写英文与短横线，例如 `scroll-animation.md`。
- 记录适用场景、实现思路和局限；涉及某个作品时附上相对链接。
- 新增笔记后，在本文件下方添加索引。
